# Проект "Виджет банковских операций клиента"

## Описание:

Проект "Виджет банковских операций клиента" - это веб-приложение на Python для выполнения некоторых банковских операций. Приложение маскирует номер карты и счёта пользователя, создаёт список данных по заданному ключу, сортирует этот список по дате.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/Nastya310611/Project1.git
```

2. Установите зависимости:
```
pip install -r requirements.txt
```

3. Создайте базу данных и выполните миграции:
```
python manage.py migrate
```

4. Запустите локальный сервер:
```
python manage.py runserver
```
## Использование:

1. Введите номер карты или счёта и получите маску карты или счёта
2. Введите дату в формате ISO и получите на выходе дату в формате ДД.ММ.ГГГГ
3. Введите список данных для формирования нового списка с имеющимся ключом
4. Введите список данных для сортировки по дате
5. Введите список транзакций для вывода транзакций с определённой валютой
6. Введите список транзакций для вывода описания платежа
7. Введите диапазон чисел для генерации номера карты
